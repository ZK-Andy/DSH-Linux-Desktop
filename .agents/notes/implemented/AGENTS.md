# implemented 说明

`implemented/` 的 note 描述已交付的现实，用现在时。代码挪了文件、改了名字、换了默认值或机制，描述它的 note 在同一次改动里跟着改——就地改写陈述，不追加变更历史。

当一份已交付的 note 不太可能再指导未来工作时，把它整体移进 [`archived/`](../archived/AGENTS.md)，而不是继续维护它。

### 这不代表可以改写**决定**

只更新事实性的实现描述。推翻决定本身或它的理由需要写一份新的 Agent Note 并互相链接；被完全取代的旧 note 只能按 [Agent Note 规则](../README.md)的合并条款删除。
