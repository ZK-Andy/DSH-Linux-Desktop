# Agent Notes 子树说明

Agent Note 是代理写的 RFC：保留理由、备选、后果与必需验证的持久提议与决策记录。格式与生命周期规则在 [README.md](README.md)，本文只加这个子树特有的纪律。

**每份新 Agent Note 都触发一次取代检查。** 先在现行树里搜覆盖同一决定或同一机制的旧 note，把完全或部分取代关系分类出来，同一次改动里把所有够格的 `implemented/` 旧 note 归档掉。部分取代的保持现行并互相链接。

`archived/` 下的文件是冻结的历史快照：永不编辑，也不当作现行权威，规则见 [archived/AGENTS.md](archived/AGENTS.md)。
